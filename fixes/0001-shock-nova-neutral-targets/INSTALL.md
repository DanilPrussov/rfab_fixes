# Установка и проверка на Windows

ESP уже подготовлен и находится в репозитории. Для обычной установки
достаточно Windows PowerShell; .NET SDK, Python и xEdit не требуются.
Это кандидат для игрового теста, статус `ready-for-test`.

## Получить ZIP

Из корня репозитория в PowerShell:

```powershell
git pull --ff-only
powershell -NoProfile -ExecutionPolicy Bypass -File .\fixes\0001-shock-nova-neutral-targets\prepare-mo2.ps1 -Mo2Root "D:\RFAB\MO2"
```

Заменить `D:\RFAB\MO2` на свою папку MO2, внутри которой находятся
`mods\RFAB\RFAB.esp` и `profiles`. Команда проверит SHA-256 базы и готового
ESP, затем создаст `dist\0001-shock-nova-neutral-targets.zip`.
Повторный запуск использует существующий архив, если его содержимое совпадает.
Исходные файлы MO2 команда только читает.

Если появилось `SHA-256 mismatch`, остановиться и прислать текст ошибки:
патч подготовлен для конкретной исследованной версии RFAB. Проверку не обходить.
Если `File not found`, проверить указанный путь к MO2.
Параметр `ExecutionPolicy Bypass` действует только для этого запуска PowerShell.

## Установить в MO2

1. Сделать копию профиля `Default` для теста, включить отдельные сохранения
   профиля и поместить туда **копию сохранения до инцидента с орками**.
2. Нажать «Установить мод из архива», выбрать созданный ZIP.
3. Включить мод слева и `RFAB-ShockNova-NeutralTargets.esp` справа.
   ESP поставить после `RFAB.esp`, для теста — в конце текущего списка.
   Автоматическую сортировку всей сборки запускать не нужно.

Патч содержит одну запись MGEF. Прямые мастера — `Skyrim.esm` и `RFAB.esp`;
остальные обычные зависимости RFAB должны быть установлены.
В папку игры вручную ничего копировать не требуется.

## Проверить

1. С отключённым патчем загрузить исходную копию сохранения. Надеть кольцо
   «Критический разряд» и амулет «Высвобожденное электричество», атаковать
   великана электричеством рядом с орками в начале «Проклятого племени».
   Записать исходные и итоговые штраф, репутацию и состояние орков.
2. Выйти из игры, включить патч, загрузить **ту же исходную копию сохранения**
   и повторить атаку. Собственное AoE исходного заклинания не должно
   попадать по оркам: проверяем дополнительную молнию комплекта.
3. Ожидание: молния продолжает повреждать великана и других врагов рядом;
   орки не теряют здоровье, не становятся враждебными, штраф и репутация
   не меняются. Отдельно проверить спутника рядом с врагом.

Сообщить результат: сработала ли молния, получили ли орки урон,
изменились ли агрессия/штраф/репутация. Если урон исчез, но штраф остался,
это тоже отрицательный результат, который поможет следующей диагностике.

Откат: отключить мод/ESP и вернуться к сохранению до установки.
Не использовать сохранение, сделанное с патчем, как контрольное.
