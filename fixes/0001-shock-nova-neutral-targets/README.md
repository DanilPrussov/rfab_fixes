# 0001-shock-nova-neutral-targets — молнии комплекта задевают нейтральных

- Статус: `ready-for-test`
- Этап: ESP-кандидат подготовлен 2026-10-20; игровой тест не выполнен.
- Категория: данные ESP, выбор получателей вторичного урона.
- Профиль: `Default`; исходный мод: `RFAB`.
- Версии RFAB / Skyrim runtime / SKSE: неизвестны. Поля версии `RFAB/meta.ini`
  пустые; базовой игры в локальной копии MO2 нет.
- Следующий шаг: установить через MO2 и выполнить A/B-тест с орками.
- Установленная сборка не изменена. Готовый ESP находится в `payload/`.
- Короткая инструкция и одна команда PowerShell: [INSTALL.md](INSTALL.md).

## Вывод

**Подготовлен отдельный ESP без игровой DLL и без изменения Papyrus.**
В единственный MGEF конечного урона добавлено условие допуска получателя.
Библиотека Mutagen создала плагин, независимый валидатор подтвердил сохранность
всех остальных полей и ссылок. Это кандидат для испытания: отсутствие штрафа
и потери репутации нужно подтвердить в игре.

Сложность данных небольшая; основная неопределённость — реакция движка
на попадание в NPC, которому запрещено применение эффекта. Если узкая правка
не поможет и потребуется перестройка механики либо нативный перехват,
задачу отложить согласно ограничению пользователя.

## Проблема

В данных комплект состоит из кольца «Критический разряд»
и амулета «Высвобожденное электричество». По сообщению пользователя,
он вызывает дополнительные молнии при поражении электричеством.
При атаке великана в начале «Проклятого племени»
вторичный AoE задел орков, после чего возникли штраф и потеря репутации.

Критерий успеха: комплект продолжает поражать врагов с исходными уроном,
радиусом и условиями срабатывания, но его вторичная молния не наносит урон
нейтральным и дружественным NPC и не вызывает из-за них агрессию,
штраф или потерю репутации.

## Найденная цепочка

Это **единый комплект**, а не две независимые новы. Его бонус в данных
называется «Электрический резонанс» / «Комплект молний».

Ниже указаны local ID внутри `RFAB.esp`, без зависящего от загрузки префикса.
В сырых заголовках исследованного файла префикс `06`; это не обещание
консольного FormID в игре.

| Тип / local ID | EditorID | Роль |
| --- | --- | --- |
| ARMO `00331A` | `RFAB_Amulet_ShockAccessories_Amulet` | Амулет, свойства SetKW/SetSpell |
| ARMO `00331F` | `RFAB_Ring_ShockAccessories_Ring` | Кольцо, дополнительно выдаёт tracker |
| SPEL `0A4B3A` | `RFAB_Spell_Set_ShockAccessories` | Бонус полного комплекта |
| SPEL `0A4B3C` | `RFAB_Spell_ShockAccessories_Tracker` | Плащ при выполнении условий комплекта |
| MGEF `0A4B3D` | `RFAB_Effect_ShockAccessoriesTracker` | Плащ со ссылкой на `0CDF53` |
| SPEL `0CDF53` | `RFAB_Spell_ElectricVortex` | Первичный выбор целей |
| MGEF `0CDF45` | `RFAB_Effect_ElectricVortexCloak_Script` | Скрипт вызывает вторичную молнию |
| SPEL `1124B1` | `RFAB_Spell_FingerOfTheMountain` | Три ступени урона: 150 / 200 / 250, Area=5 |
| MGEF `1124AF` | `WB_D100_FingersOfTheMountainNew_Effect_LightningStrike` | Конечный эффект урона |
| EXPL `1124B0` | `WB_DestructionShock_Explosion_FingersOfTheMountain_2` | Взрыв и визуальный объект |

В `0CDF53` **уже есть** `IsHostileToActor(PlayerRef) == 1` на обоих
effect entries (`0CDF44`, `0CDF45`). Поэтому просто добавить проверку
внешнему плащу или в скрипт перед Cast недостаточно.

VMAD `0CDF45` привязывает `RFAB_ElectricVortex_Script` к `1124B1`.
Существенный участок PSC и исполняемого PEX согласован:
`OnEffectStart(akTarget, akCaster)` вызывает
`Spell.Cast(akCaster, akTarget)`, затем воспроизводит звук.

У `1124B1` три эффекта с одним MGEF `1124AF`: magnitude 150/200/250,
area 5, duration 0. Их существующие CTDA проверяют только перки (`HasPerk`,
Run On: Target). **Проверки враждебности вторичных получателей нет;
на самом MGEF `1124AF` CTDA также отсутствуют.**

MGEF имеет Hostile, Detrimental, No Duration. У EXPL `1124B0`
Damage=0, Force=128, Radius=64; отдельного Enchantment и Spawn Projectile
нет, Chain не выставлен. Placed Object — визуальный ACTI `1124AE`
со скриптом удаления после задержки. Нулевой Damage не доказывает отсутствие
побочных событий от взрыва — их всё равно проверить в игре.

Скан всех подзаписей RFAB, включая сжатые записи и варианты self-префикса
`06…FF`, нашёл только один прямой потребитель `1124B1` — VMAD `0CDF45`;
`1124AF` используется только тремя EFID этого заклинания.
Это поддерживает узкий override MGEF. Динамические обращения из DLL/PEX
по имени или числу таким сканированием полностью не исключаются.

## Реализованное изменение

В `payload/RFAB-ShockNova-NeutralTargets.esp` ровно один override:
MGEF `RFAB.esp:1124AF`. В Target Conditions добавлено:

```text
IsHostileToActor(PlayerRef [Skyrim.esm:000014]) == 1
Run On: Subject; без OR
```

Сохранены все исходные поля MGEF, русский текст в UTF-8, флаги, визуал,
ссылки на звуки и взрыв. Существующие SPEL/PEX и ступени урона не менялись.
Прямые мастера патча: `Skyrim.esm`, `RFAB.esp`. Это обычный ESP без ESM/ESL
и без новых игровых записей; HEDR 1.7 сохранён от базы, formVersion MGEF=44.

Размер ESP: 799 байт. SHA-256:
`640c860aca45858c89946ecc34a92a178022428f8d3e060ced1edc4a68d94994`.

Плагин записан типизированной библиотекой Mutagen.Bethesda.Skyrim 0.54.4;
hex-правки не применялись. Код генератора, зафиксированные NuGet-зависимости
и команды воспроизведения находятся в [src/README.md](src/README.md).
Python-анализатор используется только для независимого чтения/проверки.

На Windows команда из [INSTALL.md](INSTALL.md) проверяет хеш RFAB.esp
и хеш готового ESP, затем упаковывает его в ZIP для MO2. Пересборка генератора
для установки не нужна. Другая база блокирует упаковку до повторной диагностики.

После установки нужны A/B-сценарии из [TESTING.md](TESTING.md).
Если здоровье защищено, но штраф/агрессия остаются, отдельно исследовать
событие попадания и EXPL; при существенном усложнении остановить направление.

Функция `IsHostileToActor` — штатная CTDA-функция Skyrim №719:
[схема TES5Edit](https://github.com/TES5Edit/TES5Edit/blob/dev-4.1.6/Core/wbDefinitionsTES5.pas#L594).
Предпочтение Target Conditions самого MGEF основано на различии допуска
к эффекту и условий его активности в SPEL:
[Creation Kit: Magic Effect](https://ck.uesp.net/w/index.php?section=16&title=Magic_Effect).
Это не гарантия порядка обработки crime относительно CTDA.

Не предлагать как фикс: отключение репутации, изменение `iAllyHitNonCombatAllowed`,
снятие Hostile, удаление AoE, уменьшение урона/радиуса или замена DLL.
Они либо не решают отбор целей, либо меняют другой игровой смысл.
